# Per-game shadow hit-rate floors for `trace-golden -- pgxp`, in percent.
#
# A ratchet, exactly like test-roms-pl's floor.txt: set from the first measured
# sweep rounded DOWN to the nearest whole percent, so a propagation regression
# shows up as a drop rather than as a subtly worse picture nobody notices.
# Re-pin deliberately, in its own commit, when propagation improves.
#
# A workload with no line here is a WARNING, not an error — unlike a missing
# trace golden, which stays fatal. A new rip should not fail the gate before
# anyone has measured it.
#
# Measured 2026-08-30, the first sweep after `swc2` joined the propagation set
# (adding it took crash from 0% to 99% and silent-hill from 0% to 76%), and
# re-pinned 2026-08-31 for the three workloads `mtc2`/`lwc2` into SXY raised:
# crash-warped 92 -> 99, crash-2 94 -> 99, tr1 47 -> 92.
#
# THREE LINES HERE ARE ABOVE WHAT HEAD MEASURES and are deliberately left that
# way: crash-bandicoot-europe-edc (98.9% against 99), silent-hill-usa (75.8%
# against 76) and spyro-the-dragon-usa (40.9% against 48). None of the three is
# consistent with this file's own "measured, rounded down" rule, so all three
# were higher on 2026-08-30 and have since dropped. `mtc2`/`lwc2` did not cause
# it — the drop is present in the sweep taken immediately before that change —
# and the likeliest cause is that the memory-card /ACK commits moved SIO timing,
# so a 600M-instruction run now reaches different geometry. Lowering these to
# match would erase the only record that it happened; spyro's 7-point gap in
# particular is worth a look before anyone re-pins it.
#
# Three of these are honestly low and are NOT a bug to chase blindly:
#   bios-only    0%  — a disc-less boot never draws the licence logo, and the
#                      rest of the BIOS front-end is 2D.
#   croc, mgs, resident-evil — all three resolve exactly 25,854 vertices, which
#                      is the BIOS licence logo alone, identical on every disc.
#                      Their OWN geometry resolves nothing, with identity_fail
#                      at 0, so no shadow entry ever exists for it rather than a
#                      stale one being rejected. Croc ends a 600M run with ZERO
#                      live RAM shadow entries where silent-hill has 6,450, so
#                      its vertices never reach RAM by `sw` or `swc2` at all.
#                      That points at CPU-side geometry or an idiom not yet in
#                      the propagation set, and it is the next thing to chase.

# --- A second ratchet lives below: per-workload CEILINGS on `clamped`. ---
#
# `clamped` counts a resolved vertex whose pre-clamp f32->16.16 conversion
# disagreed with the pixel `primitive.zig`'s `toFixed` actually clamped it
# into (see CLAUDE.md's PGXP rules and the `ps1-pgxp` skill). The clamp keeps
# the vertex correct on screen, so this is not a hit rate and is not read the
# same way: it is a RATCHET on how often the clamp has to intervene, exactly
# like the percentages above are a ratchet on how much resolves. A workload
# with no `clamped` line here WARNs instead of failing, same as one with no
# hit-rate floor above.
#
# Syntax: `clamped <workload key> <count>`, parsed by `parseClampCeilings`
# (and skipped by the hit-rate parser above, `parseFloors`, on the `clamped `
# prefix) — both ratchets share this one file on purpose, so a workload's two
# numbers are read together.
#
# Measured 2026-09-10, a full unfiltered sweep, the same run this file's
# hit-rate section was last measured against (no percentage above moved).
# Nine of ten workloads clamp ZERO vertices in 600M instructions; only
# crash-bandicoot-2 hits the f32 rounding edge, twice. Ceilings are pinned at
# exactly the measured count, not rounded — unlike a percentage there is no
# noise to round away, and a workload that has never needed the clamp should
# fail the instant a new producer makes it need one.
clamped bios-only 0
clamped crash-bandicoot-europe-edc 0
clamped crash-bandicoot-warped 0
clamped crash-bandicoot-2-cortex-strikes-back-europe-australia-en-fr-de-es-it-edc 2
clamped resident-evil-usa 0
clamped croc-legend-of-the-gobbos 0
clamped silent-hill-usa 0
clamped mgs 0
clamped tr1-usa-v1-1 0
clamped spyro-the-dragon-usa 0
