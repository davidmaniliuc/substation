# A ratchet, exactly like test-roms-pl's floor.txt: set from the first measured
# sweep rounded DOWN to the nearest whole percent, so a propagation regression
# shows up as a drop rather than as a subtly worse picture nobody notices.
# Re-pin deliberately, in its own commit, when propagation improves.
#
# A workload with no line here is a WARNING, not an error — unlike a missing
# trace golden, which stays fatal. A new rip should not fail the gate before
# anyone has measured it.
#
# Measured 2026-08-30, the first sweep after `swc2` joined the propagation set
# (adding it took crash from 0% to 99% and silent-hill from 0% to 76%).
#
# Three of these are honestly low and are NOT a bug to chase blindly:
#   bios-only    0%  — a disc-less boot never draws the licence logo, and the
#                      rest of the BIOS front-end is 2D.

#                      is the BIOS licence logo alone, identical on every disc.
#                      Their OWN geometry resolves nothing, with identity_fail
#                      at 0, so no shadow entry ever exists for it rather than a
#                      stale one being rejected. Croc ends a 600M run with ZERO
#                      live RAM shadow entries where silent-hill has 6,450, so
#                      its vertices never reach RAM by `sw` or `swc2` at all.
#                      That points at CPU-side geometry or an idiom not yet in
#                      the propagation set, and it is the next thing to chase.
